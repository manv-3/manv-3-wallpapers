# manv-3-wallpapers

A curated collection of high-resolution desktop wallpapers for Hyprland, Wayland, and Quickshell desktop setups.

Companion wallpaper pack for [manv-3-nix-configs](https://github.com/manv-3/manv-3-nix-configs).

---

## Setup & Integration

To clone and use these wallpapers on a new machine:

```bash
mkdir -p ~/Pictures
git clone https://github.com/manv-3/manv-3-wallpapers.git ~/Pictures/Wallpapers

# Link to ~/.config/wallpapers for quickshell integration
ln -sf ~/Pictures/Wallpapers ~/.config/wallpapers
```
